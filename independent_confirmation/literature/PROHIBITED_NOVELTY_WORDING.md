# Prohibited novelty wording

The following words or claims are unsupported for this project and must not appear in a manuscript, cover letter, abstract, repository release, or venue communication:

- first
- unprecedented
- novel
- proves
- state of the art
- introduces claim-specific validation as a new principle
- discovers that replay differs from statistical pairing
- invents event-keyed randomness
- invents common random numbers or paired-seed inference
- first prospective planted-fault benchmark for validation tools
- independently validated benchmark
- externally validated synthetic holdout

Allowed factual wording, if this engineering work is ever described outside a research manuscript:

> This private repository explored a deterministic implementation that maps five established evidence categories to claim-specific statuses. A hostile literature review found that the scientific contribution did not exceed packaging prior methods, and no new confirmatory campaign was run.
