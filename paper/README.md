# APS Open Science research paper

This directory contains the complete research-paper workspace for
**A Validity Ladder for Seed-Matched Evaluation of Game-Playing Agents**. The
paper is a methods-led Regular Article: it introduces the Paired Evaluation
Validity Ladder (PEVL), validates it in a standalone synthetic testbed, and uses
the game-agent project as a fail-closed case study. It is intentionally
separated from the competition-development workspace at the repository root.

## Directory map

| Path | Contents |
| --- | --- |
| `data/` | Canonical outcomes, machine-readable summaries, fresh raw evaluation records, and ablation evidence |
| `figures/` | PEVL methods/case-study figures plus concise appendix figures in PDF and PNG |
| `tables/` | Generated PEVL and appendix REVTeX table fragments |
| `protocol/` | Prospectively frozen PEVL, confirmation, and ablation protocols |
| `scripts/` | Analysis, table/figure generation, release assembly, and audit programs |
| `supplement/` | PEVL framework, provenance, data/model cards, rights review, literature audit, checklist, and audits |
| `synthetic/` | Self-contained synthetic PEVL implementation, fixtures, and generated detection matrix, prepared for release pending license approval |
| `release/` | Sanitized processed-data package, including a standalone copy of the synthetic testbed |

Core numerical prose is generated from the machine-readable results through
`results.tex`, `results_macros.tex`, and `diagnostic_macros.tex`. The claim
ledger records the evidence, commit, artifact hash, statistical method,
limitation, and disposition for every reviewed claim.

## Verification

From the repository root:

```bash
python -B paper/synthetic/pevl_synthetic.py verify
python -B paper/scripts/audit_seed_namespace.py
python -B paper/scripts/audit_stochastic_sources.py
python -B paper/scripts/analyze_pevl.py
python -B paper/scripts/build_pevl_result_macros.py
python -B paper/scripts/build_pevl_artifacts.py
python -B paper/scripts/build_claim_ledger.py
python -B paper/release/evaluation/verify_processed.py
python -B paper/release/evaluation/verify_pevl.py
python -B paper/scripts/red_team_audit.py
```

Prospective game acquisitions are controlled by
`paper/scripts/run_pevl_experiments.py`. The orchestrator refuses to run unless
the protocol and evaluation code are committed, clean, and pushed to the
current `origin` branch; it also enforces artifact hashes and the frozen
preflight gate. Restricted full traces remain under the ignored `artifacts/`
tree. Processed analysis is generated by `paper/scripts/analyze_pevl.py`.
Terminal manuscript prose is generated by
`paper/scripts/build_pevl_result_macros.py`, and PEVL tables and figures are
generated only from those analyzed outputs by
`paper/scripts/build_pevl_artifacts.py`. Conditional factorial effects and
artifacts are omitted unless the factorial branch is admitted. The claim ledger
is then rebuilt from the same validated terminal files.

To rebuild the sanitized release atomically and rerun its verifier:

```bash
python -B paper/scripts/build_release.py
```

To compile the manuscript, run REVTeX from this directory:

```bash
cd paper
tectonic main.tex
```

## Current release status

The scientific package is designed to fail closed under automated data,
provenance, citation, figure, manifest, and restricted-content checks. Public
release and journal submission still require author-confirmed metadata, an
approved license and rights review, and archival DOI metadata. The placeholder
license grants no redistribution rights.
