# What Will Be Submitted

## 1. WHAT APS GETS

- Manuscript PDF (single file, all text and figures)
- Cover letter
- Author names and affiliations
- Corresponding author + ORCID
- Title, abstract, article type (Protocol Article)
- PhySH subject terms
- Funding and conflict-of-interest entries
- Data Availability Statement
- Public-archive DOI (once you authorize the archive; otherwise the honest
  "not yet public" wording is used)
- Reviewer suggestions, if you choose to name any
- Supplemental Material PDF — only if ever actually needed (currently not
  used; the appendices keep the paper self-contained)

## 2. WHAT GOES IN THE PUBLIC ARCHIVE

(Only after your release approval — see questionnaire questions 13–17.)

- Sanitized protocol/software package
- Synthetic conformance suite
- Processed, neutralized diagnostics
- Analysis code
- Figure source data
- Protocol transcriptions
- Schemas
- Tests
- Reproduction instructions
- License (MIT for code / CC BY 4.0 for data & docs, per your answers)
- DOI metadata

## 3. WHAT DOES NOT GET PUBLISHED

- Restricted game engine or binaries
- Third-party opponent packages
- Raw private traces
- Game/card assets
- Policy weights
- The private repository
- Internal AI review simulations
- The prior journal rejection
- Claim-ledger internals
- Human closeout documents

## 4. WHAT THE HUMAN MUST CLICK/DO

1. Approve your questionnaire answers (they become the formal statements).
2. Approve the public release (or defer it).
3. Review the final PDF.
4. Optionally send the scope-inquiry email.
5. Manually upload to APS (the tooling never submits for you).
