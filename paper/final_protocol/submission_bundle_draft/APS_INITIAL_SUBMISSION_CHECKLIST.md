# APS initial submission checklist

- [x] Single self-contained PDF (text + figures): manuscript.pdf
- [x] Cover letter (article type, problem, protocol, results, novelty boundary,
      scope relevance, overlap-history pointer, availability, AI disclosure, reviewers)
- [x] Author/affiliation/corresponding-author metadata prepared (placeholders until YAML)
- [x] Corresponding-author ORCID flagged REQUIRED (APS rule)
- [x] Title/abstract file (abstract within internal 175-210-word bound)
- [x] Data Availability Statement (Version B; A auto-selected only when authorized)
- [x] AI-use disclosure in Methods + Acknowledgment locations + cover-letter pointer
- [x] PhySH candidates verified against official taxonomy (star one primary in widget)
- [x] Editorial information: scope inquiry drafted (unsent); overlap disclosure file
- [ ] Suggested/excluded reviewers (optional; human selects)
- [ ] Funding/conflict entries completed in the submission form (human)

Excluded from this bundle on purpose: rejection history, internal desk
simulations, closeout forms, claim-ledger internals, full AI-use log (available
on request), private repository, raw engine data, restricted traces, no-license
review package, virtual environments, worker-agent reports.
