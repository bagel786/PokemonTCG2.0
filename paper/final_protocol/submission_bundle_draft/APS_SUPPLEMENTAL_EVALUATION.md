# Supplemental Material evaluation

Decision: NO separate Supplemental Material PDF is used.

Rationale: APS SM policy reserves supplements for nonessential-but-useful
material; the manuscript must stand alone. All technical depth needed to
verify claims is already in the appendices (trace record fields, factorial
algebra, reweighting details, artifact/rights boundary), and the executable
companion (future DOI archive) carries what must not live in a journal PDF
(schemas, rules, tests). Using SM instead of the archive would also violate
the APS note that SM files are not FAIR data-sharing substitutes.

If the human later opts into an SM PDF, it needs: self-contained title/author
block placeholder, README.TXT with Description field, citation line 'See
Supplemental Material at [URL] for ...' in the main reference list, and all
SM references mirrored in the main bibliography.
