This directory is the public-only release candidate for the claim-specific
seed-matching study. It contains no restricted Pokémon engine assets, opponent
packages, or historical raw traces.

Status: **LOCAL DRAFT - NOT DEPOSITED - NOT SUBMISSION-READY**.

Start with `REPRODUCIBILITY.md` and `DATA_CARD.md`. `MANIFEST.sha256` is generated
last, after the package has been assembled and audited. The release reports the
study's negative readiness result; it must not be described as a validated
universal framework.
