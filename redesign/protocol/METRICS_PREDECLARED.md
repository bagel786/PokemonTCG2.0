# Predeclared Utility Metrics (FROZEN BEFORE OUTCOME ACQUISITION)

**Freeze date:** 2026-08-26 · **Status:** FROZEN · Supersedes nothing; amended only via documented erratum before final runs.

Every metric below declares: estimand, analysis unit, ground truth, aggregation rule, uncertainty method, success criterion, limitations. Machine-readable twin: `metrics.json`.

**Global conventions.**
- Analysis unit for decision-metrics = (system × scenario × seed × method × branch) cell; a "case" is one cell whose ground-truth label ∈ {VALID, INVALID, DOWNGRADE}.
- NOT_APPLICABLE cells are excluded from every denominator (denominators always reported).
- Uncertainty: Wilson 95% score intervals for proportions (reported with exact denominators); Clopper–Pearson intervals where a conservative bound is claimed.
- No metric may be added, removed, or redefined after any final outcome row is read.

---

### M1. Invalid-claim detection rate
- **Estimand:** P(decision ∈ {SUPPRESS, FAIL_CLOSED} | GT=INVALID), per method×branch×system.
- **Unit:** case. **GT:** scenario label table (frozen). **Aggregation:** pooled proportion per (method, branch) across systems and scenarios contributing that branch's GT=INVALID cases; also reported per-scenario.
- **Uncertainty:** Wilson interval. **Success criterion (framework):** ≥0.95 on every branch with ≥5 invalid cases.
- **Limitations:** scenarios are designed failures; rates do not estimate natural-failure prevalence.

### M2. False-suppression rate
- **Estimand:** P(decision ∈ {DOWNGRADE→soft, SUPPRESS→hard} | GT=VALID), per method×branch×system; soft/hard tracked separately.
- **Aggregation:** pooled per (method, branch); headline uses hard+soft combined, both components reported.
- **Success criterion:** ≤0.10 pooled for the framework; any baseline beating the framework on (M1,M2) jointly must be reported as such in the abstract if N≥5 cases support it.
- **Limitations:** VALID labels reflect construction-time validity, not robustness to unmodeled future modifications.

### M3. Missed-failure rate
- **Estimand:** P(decision=ADMIT | GT∈{INVALID}) plus lenient-admission P(ADMIT | GT=DOWNGRADE) reported separately ("caveat-blindness").
- **Success criterion:** framework ≤0.05 on hard-invalid cells.

### M4. Coverage / calibration of uncertainty statements
- **Estimand:** empirical coverage of 95% paired-difference intervals under S0/S3 (coupled) and B5-style hierarchical intervals under S8, evaluated against known-by-construction zero or fixed effect values (A/A arms and shifted-mean arms generated by construction in the statistics layer, not by new game outcomes).
- **Unit:** one constructed null or alternative replicate. **Aggregation:** coverage proportion ± Clopper–Pearson; calibration plot data = nominal vs empirical.
- **Success criterion:** 95% nominal → empirical ∈ [0.90, 0.98] (Monte Carlo tolerance declared in ANALYSIS_PLAN).
- **Limitations:** parametric bootstrap used for hierarchical intervals; miscoverage may reflect bootstrap, not design.

### M5. Type-I error under known-zero effects
- **Estimand:** P(paired test rejects at α=0.05 | true difference = 0) under S0-coupled sampling using outcome pairs from A/A constructions (holdem: same-policy mirror hands; ising: equal temperatures).
- **Uncertainty:** binomial MCSE = sqrt(αβ/N) reported.

### M6. Power under known-nonzero effects
- **Estimand:** 1 − β at α=0.05 for the frozen effect sizes (holdem: random-vs-conservative opponent chips; ising: T 2.269 vs 2.9 mean|m|), for paired-coupled vs independent designs at equal budget.
- **Aggregation:** power curve over N ∈ {10,20,40,80} via resampling of stored outcome pairs.

### M7. Estimator variance (CRN vs independent)
- **Estimand:** ratio R = Var(d_paired)/Var(d_independent) estimated from the same seed bank (paired differences within seed; independent differences formed by cross-seed matching), with delta-method CI on log R.
- **Success criterion (interesting-reporting rule, not gate):** R<1 with CI excluding 1 ⇒ coupling helps; R≥1 ⇒ report honestly even when framework admitted D.

### M8. Conclusion changes
- **Estimand:** fraction of (scenario, seed-bank) replicates where the sign/significance of the substantive comparison flips between method-recommended analyses (e.g., B4-unpaired vs B7-recommended analysis).
- **Unit:** scenario×bootstrap-resample.

### M9. Runtime overhead
- **Estimand:** median wall-clock seconds per schedule-row execution per method (instrumentation included, systems excluded); ratio vs B0.
- **Unit:** row execution; logged as runtime_a/runtime_b + harness timestamps.

### M10. Storage overhead
- **Estimand:** bytes/artifact (projection + draw-log cap + evidence bundle), median and p95 per method tier.

### M11. Trace-acquisition overhead
- **Estimand:** fraction of run time spent in draw logging/instrumentation, measured as (adapter instrumented − adapter bare)/bare on a 50-run microbenchmark, per system.

### M12. Human/configuration complexity
- **Estimand:** count of required declared fields/decisions to operate each method (enumerated from code constants; listed exhaustively in FAILURE_INJECTION_MANIFEST appendix).
- **Aggregation:** integer counts + binary flags (needs white-box RNG access? needs repeats? needs ontology?).

### M13. Cross-system consistency
- **Estimand:** Kendall τ between holdem and ising method rankings (by M1−M2 tradeoff score) and sign agreement of key contrasts (R<1?, detection ordering).
- **Success criterion:** qualitative agreement expected; disagreement reported as boundary condition, not hidden.

---

## Multiplicity
Primary family = {M1, M2} across branches; Holm correction within family for method-vs-framework contrasts. Secondary metrics exploratory, labeled as such.

## Stopping rules
All planned cells execute once; no interim looks; reruns only for crashes (logged, result-excluded crash log).

## Success criteria for the overall study (predeclared)
The framework is *worth recommending* iff: M1≥0.95 AND M2≤0.10 AND no simpler baseline dominates it jointly on (M1, M2, M9). If a simpler baseline dominates, the paper's conclusion says so.
