# V1 Failure Analysis and V2 Repair Ledger

**Written before any V2 scientific implementation.**  This document is the
required design gate for V2.  V1 remains immutable on branch
`paper/claim-specific-prospective-redesign-20260826`; its closeout commit is
`9103df7b5e4f673a1358c30644b451344dc9ec9f` and its prospective freeze is
`62ad87893da926d0a67e9dc8ea9b99f81261b7ed`.

## Audit scope

The audit covered V1's handoff, novelty and feasibility reports, method and
equation audits, protocol and analysis documents, seed/failure/decision
manifests, canonical/generated framework, adapters, RNG, scenarios, runner,
classifier, baselines, manuscript, tests, complete raw schema and row
inventory, every aggregate artifact, and the independent reaggregation.
The retained raw file contains 35,014 rows (34,160 decisions and 854 outcome
pairs).  Decision rows contain only branch, decision, ground truth, method,
scenario, score class, seed, and system; outcome rows contain only aggregate
outcomes, seeds, runtimes, bytes, and draw counts.  This is insufficient for
several V1 claims and predeclared metrics.

## V2 architecture consequences

These failures require more than a classifier patch.  V2 must use an explicit
evidence model, claim/subclaim capability matrix, independently derived truth,
three-stage blinded execution, a real Philox event ledger, actual mechanisms,
an analytic hierarchical-Gaussian oracle, and an output contract that makes
M1--M13 computable before the protocol is frozen.  The final schedule and
analysis code will be frozen and pushed before any final-seed execution.

## Gate decision

**V1 is useful as a transparent negative result and design audit, but it does
not validate the framework.**  V2 implementation may now begin, subject to
every repair above being traceable to a test and freeze artifact.
